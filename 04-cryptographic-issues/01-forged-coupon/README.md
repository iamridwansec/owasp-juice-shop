# Forged Coupon: Forge a Coupon Code That Gives at Least 80% Discount

**Objective:** Forge a coupon code that gives you a discount of at least 80%.

**Difficulty:** ★★★★★★ (6 stars) — Cryptographic Issues

## Background

Juice Shop's discount coupon codes are generated by taking a plain string in the format:

```
<MONTH><YEAR>-<PERCENT>
```

for example `JAN17-50` for a 50% discount valid in January 2017 — and encoding it using **Z85**, the ZeroMQ implementation of Base85. This is just an *encoding*, not encryption or a signed token: there is no secret key, HMAC, or server-side check tying a coupon's validity to anything beyond the string being a correctly Z85-decodable value matching the current month. This means anyone who deduces the format and encoding scheme can forge their own valid-looking coupon for any discount they choose.

## Steps Taken (Reverse Engineering Path)

### 1. Found a backup file listing the project's dependencies

Solved the **"Access a salesman's forgotten backup file"** challenge to retrieve `package.json.bak` from the exposed `/ftp` directory, listing the project's npm dependencies.

### 2. Narrowed down the candidate crypto/hashing libraries

Among the dependencies, three stood out as candidates for coupon generation: `hashids`, `jsonwebtoken`, and `z85`.

### 3. Confirmed z85 as the coupon encoding library

Checked the [z85 package on npmjs.com](https://www.npmjs.com/package/z85) and its "Dependents" tab, confirming it is used for coupon code creation.

### 4. Installed a Z85 command-line tool

With Node.js available locally, installed a simple CLI for Z85 encoding/decoding:

```bash
npm install -g z85-cli
```

### 5. Obtained a real, currently valid coupon code

Checked the official Juice Shop Twitter/X account (`@owasp_juiceshop`), which broadcasts a coupon code each month (e.g. a historical example: `n<Mibh.u)v`, advertised as a 50% discount).

### 6. Decoded the real coupon to confirm the format

```bash
z85 -d "n<Mibh.u)v"
```

Result:
```
JAN17-50
```

This confirmed the exact plaintext format: `<MONTH><2-digit year>-<discount percent>`.

### 7. Encoded a forged coupon for the current month at 80%+ discount

Built a new plaintext string using the current month/year and a discount of 80% or higher, e.g.:

```bash
z85 -e "JAN17-80"
```

Result (example):
```
n<Mibh.v0y
```

(The actual month/year abbreviation used should match whatever month/year the challenge is attempted in.)

### 8. Redeemed the forged coupon

Added a product to the basket, entered the forged Z85-encoded coupon code on the **Your Basket** page, and redeemed it.

### 9. Checked out

Completed the checkout process with the forged coupon applied, as the challenge requires checking out (not just redeeming) to be marked solved.

## Result

Challenge solved — confirmed by the in-app success notification and the Score Board.

## Alternative Solution Paths (Not Used, Noted for Reference)

- **Pattern analysis path:** A list of old coupon codes (from the same `coupons_2013.adoc.bak` backup file) shows a clear pattern in their last 5 characters (e.g. most ending in `gC7sn`, one ending in `gC7ss` for a higher December discount). One could brute-force/trial-and-error redeem variations of the known codes until hitting 80%+, without needing to understand Z85 at all.
- **Cloud computing path:** From February 2019 onward, Juice Shop's coupon tweets are generated by an automated bot (`juicy-coupon-bot`), whose public GitHub repository can be inspected. Its commit history reveals an earlier version that generated coupons locally (pre-dating an AWS Lambda-based API call), which can be used directly to generate valid Z85-encoded coupons the same way as the reverse-engineering path above.

## Root Cause

Coupon codes rely purely on an unauthenticated encoding scheme (Z85) rather than genuine cryptographic protection such as a signed or HMAC'd token. Since the format is predictable and there is no server-side secret involved in generating or validating the code's authenticity, anyone who deduces the format can construct arbitrary, fully valid-looking coupons for any discount percentage.
